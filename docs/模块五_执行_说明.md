## 已确认的设计决策

见 `docs/模块五_执行_方案.md`：

| 问题 | 决策 |
|---|---|
| `navigate_to` 阻塞还是非阻塞 | **阻塞** |

| 是否单独做 `safety_guard` | **不做**，超时/最大步数写在 `navigate_to` 循环内 |

## 怎么上传到 GitHub 的 tls 分支

### ⚠️ 不要这么做

**不要**在 `tls/` 里 `git init` 然后 `git push --force origin tls`。
那会替换整个提交历史，**lwj 的感知代码会从 `tls` 分支消失**。

### ✅ 网页上传（这次够用）

1. GitHub 仓库 → 切到 **`tls`** 分支
2. Add file → Upload files
3. 打开 `C:\Users\DELL\Desktop\大创\tls\`，选中 **`code` 和 `docs` 两个文件夹**拖进去
4. ⚠️ 页面底部确认 **Commit changes to branch: tls**
5. Commit

上传后 `tls` 分支上应新增：
```
code/common/{__init__,enums,schemas}.py
code/execution/{__init__,robot_backend,habitat_backend,mock_backend,task_executor}.py
code/tests/{__init__,test_execution}.py
docs/模块五_执行_方案.md
docs/模块五_执行_说明.md
```

### ✅ 仓库克隆（后续频繁改动时用）

```bash
cd <你的仓库克隆>
git fetch origin && git checkout tls
cp -r <本目录>/code/common   ./code/
cp -r <本目录>/code/execution ./code/
cp -r <本目录>/code/tests     ./code/
cp -r <本目录>/docs           ./docs
git add code/common code/execution code/tests docs
git commit -m "feat: add execution module (RobotBackend + HabitatBackend + TaskExecutor)"
git push origin tls
```

提交前 `git status` 确认**只多了这几个目录**，没有删掉别的文件。
